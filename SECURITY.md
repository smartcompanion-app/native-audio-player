# Security Policy

## Supported versions

Security fixes are released for the latest minor version. Older versions are not patched.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them through [GitHub's private vulnerability reporting](https://github.com/smartcompanion-app/native-audio-player/security/advisories/new), or by email to <hello@smartcompanion.app>.

Include the plugin version, the affected platform, and enough detail to reproduce the issue. You can expect an initial response within a week.
